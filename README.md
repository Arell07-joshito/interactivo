# Coca-Cola: Icono Global

Sitio web interactivo basado en la presentación `CocaCola.pptx`.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub te mostrará el enlace público del sitio.

El proyecto funciona como una página estática: no requiere instalación, servidor ni dependencias externas.
